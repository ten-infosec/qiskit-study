# 전체 커리큘럼

양자 컴퓨팅 → 암호(RSA·PQC) → QKD → 위성 보안으로 이어지는 학습 계획을 **이 문서 하나**에 모았습니다.

## 이 문서의 구조

이 커리큘럼은 두 개의 축으로 되어 있습니다.

| 축 | 번호 | 역할 | 진행 방식 |
|---|---|---|---|
| **개념 로드맵** | Q1~Q6 | 무엇을 이해해야 하는지 (이론) | Q1부터 순서대로 |
| **교재 실습 모듈** | 모듈 0~9 | 손으로 직접 해보기 (코드) | 모듈 0부터 순서대로 |

두 축은 **병행**합니다. 실습은 교재 페이지 순서(모듈 번호)대로 진행하고, 개념은 Q 순서대로 공부하면서 서로 연결되는 부분을 맞춰 봅니다.
각 Q 단계에 "관련 실습 모듈"이, 각 모듈에 "관련 로드맵 단계"가 적혀 있어 양쪽에서 찾아갈 수 있습니다.

## PQC 커리큘럼(Stage 1~9)과의 관계

이 저장소는 PQC 커리큘럼(HTML)의 **Stage 7(QKD · QRNG)** 에서 출발했습니다.
PQC 커리큘럼이 보안 엔지니어 실무 전체를 **넓게** 다루는 뼈대라면, Q1~Q6은 그중 양자 부분을 **깊게** 파고드는 가지입니다.
Q 번호와 Stage 번호는 **별개**입니다.

| Q 단계 | PQC 커리큘럼과의 관계 |
|---|---|
| Q1~Q3 | Stage 7의 **선수 지식** (Stage 7에는 양자역학 기초가 거의 없어서 이 부분을 채움) |
| Q4 | **Stage 1(정수론) → Stage 6(PQC) 사이의 다리**: 왜 RSA가 양자컴퓨터에 깨지고, 왜 PQC가 필요한지 |
| Q5 | Q6(실제 QKD 장비의 잡음)을 이해하기 위한 준비 |
| Q6 | **Stage 7 확장** (FPGA·HDL은 하드웨어 영역이라 Stage 7에서 따로 진행) |

PQC 알고리즘 자체(격자 기반 암호, ML-KEM, liboqs 실습 등)는 **Stage 6**에서 다루므로 이 문서에는 넣지 않습니다.

# Part 1. 개념 로드맵 (Q1~Q6)

## Q1. 수학 언어

**목표:** 양자 상태를 기호와 행렬로 읽고 쓸 수 있게 되기

**복소수와 벡터**
- 복소수: 실수부와 허수부, 크기와 위상(방향)으로 표현하기
- 벡터와 벡터공간, 선형성
- 내적과 정규화: 두 벡터가 얼마나 겹치는지 재고, 전체 확률이 1이 되도록 길이 맞추기

**디랙 표기법**
- 켓 |ψ⟩, 브라 ⟨ψ|, 내적 ⟨φ|ψ⟩, 외적 |ψ⟩⟨φ|
- 계산 기저 |0⟩, |1⟩과 아다마르 기저 |+⟩, |−⟩

**행렬과 연산자**
- 선형 연산자와 행렬 곱
- 유니터리 행렬: 되돌릴 수 있는 변환 = 양자 게이트
- 에르미트 행렬: 측정할 수 있는 양 = 관측량
- 고유값과 고유벡터
- 텐서곱: 큐비트 여러 개를 하나의 상태로 합치는 연산

**실습 아이디어:** NumPy로 H, X, Z 게이트 행렬을 만들어 곱해보고 Qiskit 결과와 비교
**관련 실습 모듈:** 모듈 4 (유니터리 행렬, I⊗H와 H⊗I), 모듈 8 (디랙 표기법)

## Q2. 물리 직관

**목표:** "측정하면 왜 상태가 바뀌는가"를 설명할 수 있게 되기

**양자역학의 기본 가설**
- 상태 가설: 양자 상태는 길이 1인 벡터로 표현된다
- 관측량 가설: 측정할 수 있는 양은 에르미트 연산자로 표현된다
- 측정 가설과 보른 규칙: 측정 결과의 확률 계산, 측정 후 상태 붕괴
- 시간 변화 가설: 상태는 유니터리 변환으로 변한다 (슈뢰딩거 방정식)

**광자와 큐비트**
- 광자의 편광과 편광 필터 실험
- 2준위 양자계로서의 큐비트
- 중첩과 위상 (전역 위상과 상대 위상의 차이)
- 블로흐 구: 큐비트 상태를 구 위의 점으로 표현하기

**보안과 이어지는 핵심 원리**
- 복제 불가 정리: 모르는 양자 상태는 복사할 수 없다
- 서로 다른 기저로 측정하면 정보가 파괴된다 (BB84의 원리)

**혼합 상태**
- 밀도 행렬: 확률적으로 섞인 상태 표현하기
- 순수 상태와 혼합 상태의 구별

**실습 아이디어:** 블로흐 구로 H, X, S 게이트 적용 전후 비교
**관련 실습 모듈:** 모듈 0~1 (같은 기저/다른 기저 측정), 모듈 4 (블로흐 구), 모듈 8 (양자화 가설, 슈뢰딩거 방정식)

## Q3. 게이트, 얽힘, 알고리즘 입문

**목표:** 작은 양자 알고리즘을 직접 짜고 왜 고전보다 빠른지 설명하기

**양자 회로와 게이트**
- 단일 큐비트 게이트: X, Y, Z, H, S, T, 회전 게이트
- 다중 큐비트 게이트: CNOT, CZ, SWAP, 토폴리
- 범용 게이트 집합: 몇 가지 게이트로 모든 연산을 만들 수 있다
- 양자 회로 구성과 모듈화 (반가산기 예제)

**얽힘**
- 얽힘 상태와 분리 가능한 상태의 구별
- 벨 상태 4가지 만들기와 측정, GHZ 상태
- 양자 순간이동
- 초고밀도 코딩: 큐비트 1개로 비트 2개 보내기

**기본 양자 알고리즘**
- 오라클: 문제를 블랙박스 회로로 표현하기
- 위상 킥백: 제어 큐비트 쪽으로 위상이 넘어오는 현상
- 도이치, 도이치-조사, 번스타인-바지라니(BV) 알고리즘

**그로버 알고리즘**
- 오라클과 확산 연산자
- 그로버 반복과 최적 반복 횟수
- 진폭 증폭: 원하는 답의 확률을 키우는 원리
- 응용: 불 켜기 게임
- 보안 영향: 대칭키 암호(AES)의 안전성을 낮추고, 키 길이를 늘려 대응

**실습 아이디어:** 2~3큐비트 그로버 구현
**관련 실습 모듈:** 모듈 4 (벨 상태, GHZ), 모듈 5 (BV 알고리즘), 모듈 7 (동적 BV)

## Q4. 쇼어 알고리즘과 양자 위협

**목표:** 양자컴퓨터가 RSA를 어떻게 깨는지 설명하고, PQC(Stage 6)가 왜 필요한지 이해하기

**쇼어 알고리즘까지 가는 길**
- 사이먼 알고리즘: 숨은 주기 찾기
- 양자 푸리에 변환(QFT)
- 양자 위상 추정
- 주기 찾기와 소인수분해의 관계 (Stage 1 정수론과 연결)
- 쇼어 알고리즘 전체 흐름
- 자원 추정: RSA-2048을 깨는 데 필요한 큐비트 규모

**양자 위협의 의미**
- RSA, ECC(타원곡선 암호)가 깨지는 이유
- 그로버 알고리즘이 대칭키(AES)에 주는 영향과의 차이 (Q3와 연결)
- 지금 수집, 나중에 해독 (Harvest now, decrypt later)
- → 대응책인 PQC(격자 기반 암호, ML-KEM, ML-DSA, 하이브리드, 크립토 애자일리티)는 **PQC 커리큘럼 Stage 6**에서 학습

**실습 아이디어**
- [rsa-from-scratch](https://github.com/ten-infosec/rsa-from-scratch)의 공격 시간 실험 결과 옆에 쇼어 알고리즘 비교 정리
- 작은 수(15, 21)를 인수분해하는 쇼어 회로 실행

**관련 실습 모듈:** 교재 모듈에는 없음 → 이 단계에 도착하면 새 모듈(10번 이후)로 추가

## Q5. 양자 오류와 오류 정정

**목표:** 실제 양자컴퓨터의 한계와 극복 방법 이해하기

**양자 오류**
- 오류의 유형: 비트 뒤집기, 위상 뒤집기, 둘의 조합
- 잡음 모델: 탈분극, 진폭 감쇠
- 결어긋남(decoherence): 양자 상태가 주변 환경 때문에 무너지는 현상
- 충실도(fidelity): 원래 상태와 얼마나 비슷한지 재는 숫자

**오류 정정 코드**
- 비트 뒤집기 3큐비트 코드, 위상 뒤집기 3큐비트 코드
- 신드롬 측정: 상태를 망가뜨리지 않고 오류 위치만 알아내기
- 안정자 체계와 안정자 코드
- 스틴 7큐비트 코드
- 표면 코드
- 결함 허용과 임계값 정리: 오류율이 기준 아래면 큐비트를 늘릴수록 정확해진다

**실제 기기와 물리적 구현**
- Transpile: 회로를 기기의 기본 게이트로 바꾸고 배치 최적화
- 큐비트 연결 구조와 SWAP 비용
- 초전도, 이온 트랩, 광자 방식의 특징과 차이

**실습 아이디어:** qiskit-aer 잡음 모델로 BB84 실행, 오류율 변화 관찰
**관련 실습 모듈:** 모듈 5 (fidelity), 모듈 6 (transpile), 모듈 7 (dynamic circuit), 모듈 9 (실제 기기)

## Q6. QKD·QRNG 심화와 위성 보안

**목표:** 실제 QKD 시스템이 어떻게 동작하고 어디가 약한지 이해하기

**QKD 프로토콜**
- BB84
- B92, E91 (얽힘 기반)
- 프로토콜별 장단점 비교

**QKD 전체 과정**
- 원시 키 생성과 기저 비교(sifting)
- QBER(양자 비트 오류율): 오류율로 도청 여부 판단하기
- 오류 보정: 서로 틀린 비트 맞추기
- 비밀성 증폭: 도청자가 알았을 수 있는 정보 지우기

**실제 시스템의 약점**
- 광자 수 분리 공격과 미끼 상태(decoy-state) 방식
- 장비 자체를 노리는 공격, 장비를 믿지 않아도 되는 방식(MDI-QKD)

**위성과 네트워크**
- 위성 QKD: 미시우스(Micius) 위성 실험
- 신뢰 노드 문제: 중계 지점을 믿어야 하는 한계
- 거리와 손실 문제, 양자 중계기

**QRNG (양자 난수 생성기)**
- 양자 측정의 무작위성으로 예측 불가능한 난수 만들기 (Q2 측정 가설과 연결)
- 컴퓨터가 만드는 의사 난수와의 차이, 암호 키 생성에서 난수가 중요한 이유

**QKD와 PQC**
- 두 방식의 장단점 비교
- 실제 보안 체계에서 함께 쓰는 방법

**실습 아이디어:** 잡음 있는 BB84에서 QBER 계산, 간단한 오류 보정 코드 작성, H 게이트 측정으로 QRNG 만들기
**관련 실습 모듈:** 모듈 2~3 (BB84 도청 없음/있음)

# Part 2. 교재 실습 모듈 상세 (모듈 0~9)

각 모듈은 **① 무엇을 배우는지 → ② 할 일 → ③ 교재에서 고쳐야 할 점 → ④ 확인 포인트** 순서로 정리했습니다.
교재 코드를 그대로 옮기지 말고, 여기 적힌 "고쳐야 할 점"을 참고해 **직접 새로 작성**합니다.

## 공통: 옛날 문법 → Qiskit 2.x 대응표

| 교재(옛날 방식) | 지금 방식 | 비고 |
|---|---|---|
| `Aer.get_backend('aer_simulator')` | `from qiskit_aer import AerSimulator` → `AerSimulator()` | 옛 방식도 동작할 수 있으나 새 방식 권장 |
| `Aer.get_backend('qasm_simulator')`, `QasmSimulator()` | `AerSimulator()` | QasmSimulator는 사라짐 |
| `q.execute(...)` | `transpile()` 후 `backend.run()` | execute는 Qiskit 1.0에서 삭제 |
| `qiskit.tools.visualization`, `qiskit.tools.monitor.job_monitor` | `qiskit.visualization` / job_monitor는 없음 | `qiskit.tools` 모듈 삭제 |
| `qiskit.providers.fake_provider.FakeNairobi` | `qiskit_ibm_runtime.fake_provider`의 가짜 백엔드 | `qiskit-ibm-runtime` 설치 필요, 이름은 설치 후 확인 |
| `prov.get_backend(...)`, `prov.retrieve_job(...)` (IBMProvider) | `QiskitRuntimeService` | 모듈 9에서 공식 문서로 최신 방식 확인 |
| `backend.run()` (IBM 실제 기기) | `SamplerV2` 사용 | 모듈 9에서 확인 |
| `c_if` 조건부 게이트 | `with qc.if_test(...):` | Qiskit 2.0에서 c_if 삭제 |
| `routing_method='stochastic'` | `'sabre'` 등 | 최신 버전에서 없을 가능성 높음 → 실행해서 확인 |
